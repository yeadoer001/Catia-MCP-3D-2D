# Catia-MCP-3D-2D

##### 项目概述

本项目是一个用于连接 **Codex** 与 **CATIA** 的 MCP Server，旨在通过 MCP 协议实现对 CATIA 的自动化控制，使 Codex 能够调用 CATIA 完成草图绘制、三维建模以及二维工程图生成等操作。

通过该服务，用户可以以自然语言或结构化指令的方式驱动 CATIA 执行建模任务，从而提升 CAD 设计流程的自动化与智能化水平。

------

##### 已实现功能

###### 1. 草图绘制控制

支持通过 Codex 控制 CATIA 创建和编辑基础草图元素，包括但不限于：

- 圆形绘制
- 矩形绘制
- 线段绘制
- 尺寸约束添加
- 几何约束设置

###### 2. 三维建模控制

支持通过 Codex 调用 CATIA 完成常见 3D 建模操作，包括但不限于：

- 拉伸建模
- 旋转建模
- 基于草图的实体生成
- 基础特征创建与参数化控制

###### 3. 二维工程图绘制

支持通过 Codex 控制 CATIA 自动生成二维工程图，包括但不限于：

- 三视图生成
- 尺寸标注
- 公差标注

- 工程图基础布局与视图管理

------

##### 修改与扩展指南

###### 1. 功能模块管理

项目中的 `tools` 文件夹用于存放 MCP Server 的所有功能模块定义。

如需新增功能，可按照现有模块结构编写对应的 Python 工具程序，并将其放入 `tools` 文件夹中。

示例扩展方向包括：

- 新增倒角、圆角、阵列等建模功能
- 新增装配体操作能力
- 新增工程图模板调用功能
- 新增材料、属性或参数化配置能力

###### 2. 自动加载机制

主程序在启动时会自动扫描 `tools` 文件夹，并加载其中定义的功能模块。

因此，新增工具文件后通常无需手动修改主程序，只需确保工具模块的接口定义符合 MCP Server 的加载规范即可。

###### 3. 一键配置

项目提供 `Setup.py` 脚本，用于实现 MCP Server 的一键化环境配置与初始化。

该脚本可用于完成依赖安装、运行环境准备、基础配置生成等操作，从而降低部署复杂度，提升项目的可维护性和可复用性。

##### 使用建议

在进行功能扩展时，建议遵循以下原则：

- 每个工具模块保持职责单一，便于维护和调试。
- 新增功能应提供清晰的参数定义与错误处理机制。
- 与 CATIA 交互的接口应尽量保持稳定，避免对主程序造成耦合。
- 建议在新增工具后补充对应的使用示例和测试说明。

- 对于复杂建模操作，可优先拆分为多个基础工具，再通过 Codex 进行组合调用。

------

##### 总结

该 MCP Server 为 Codex 与 CATIA 之间提供了标准化的连接能力，使 AI 能够参与 CAD 建模与工程图生成流程。通过模块化的 `tools` 扩展机制和 `Setup.py` 一键配置能力，项目具备良好的可扩展性、可维护性和部署便利性，适合用于智能 CAD 自动化、工程设计辅助以及参数化建模场景。
